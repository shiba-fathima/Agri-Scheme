# AgriScheme AI

A premium full-stack web application designed for farmers to discover, understand, and apply for government schemes seamlessly.

## Features
- **Smart Matching Engine**: AI matching of schemes to agricultural profiles.
- **Scheme Database**: Real-world mock data for schemes like PM-KISAN, crop insurance, and tractor subsidies.
- **Farmer Dashboard**: Track scheme recommendation matches and application statuses.
- **AI Chat Assistant**: Conversational AI for helping farmers.
- **Multi-language Support**: English, Hindi, and Kannada.

## Tech Stack
- **Frontend**: Next.js 14+ app router, Tailwind CSS v4, Framer Motion
- **Icons**: Lucide React
- **Design Pattern**: Modern glassmorphism, card-based minimal theme.

## Run Locally
```bash
npm install
npm run dev
```
